# UE_SoSe2026_Python_Programming_Sheets_Data-Science

# Programming with Python – SoSe 2026 (B.Sc. Data Science Engineering)

This repository is your pair's workspace for the whole semester.
Every weekly notebook and your final project live here.

## 1. Set up your pair repository (once, in week 2)

1. One partner opens the assignment link from Microsoft Teams and creates the team in Github, named after your pair: `Ana-Ben`.
2. The second partner opens the same link and joins that team.
3. You now have a private repository. Only you, your partner and the lecturer can see it.

## 2. Folder structure

```
week-02/   your Lecture 2 notebook
week-03/   your Lecture 3 notebook
...
project/   your final project (from week 5)
```

Name every notebook `L<week>_<names>.ipynb`, for example `L02_Ana_Ben.ipynb`.

## 3. Commit your work every week (from Colab)

1. Open the week's notebook from the link on Online Campus.
2. Work on it together during the session.
3. Before you leave: **File → Save a copy in GitHub**.
4. Choose your pair's repository and the `main` branch.
5. Set the file path to the week folder, for example `week-02/L02_Ana_Ben.ipynb`.
6. Write a clear commit message, for example `Week 2: tip calculator and grade classifier`.
7. Tick **Include a link to Colaboratory** and press **OK**.

## 4. Commit rules

- **Deadline:** your weekly notebook must be committed before the session ends.
- **Both partners commit.** Take turns: the week's driver makes the commit. Your Git history is checked for every milestone.
- **Write meaningful messages.** "update" or "final" are not acceptable.
- **Commit your own work only.** No code from other teams, and no AI-generated code (see the course rules).
- **Never delete history.** If something breaks, fix it in a new commit.

## 5. Branches and pull requests (from week 13)

From Lecture 13 you will work in VS Code, using one branch per feature and a pull request for review. Instructions follow in that session.
